# Bayrak Bilmece

This React application lets you play a flag quiz game. It also includes a simple backend server in `backend/server.ts` used to serve data during development.

## Available Scripts

Run these commands from the project root:

- `npm start` – start the development server
- `npm run build` – create a production build
- `npm test` – run tests (none included)

The app is configured for deployment to GitHub Pages at the `/bayrak-bilmece` base path.
